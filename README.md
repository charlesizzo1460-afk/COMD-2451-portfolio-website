# COMD 2451 Portfolio Website

Final project repository for COMD 2451 (Visual Design I).

## Structure

```
assets/
  <artwork>-300dpi.jpg     full size  · 300 dpi · ~600–800px wide
  <artwork>-72dpi.jpg      small size · 72 dpi  · 150px wide
  <artwork>-thumbnail.jpg  square 1:1 · 72 dpi  · 150px wide
```

Each piece of artwork has all three versions. File names use only letters,
numbers, `-` and `_` (no spaces or special characters).
